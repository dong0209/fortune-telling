# 職運羅盤

結合**八字、紫微斗數、奇門遁甲、人類圖、西洋星盤**五套命理系統的職涯決策網站。輸入出生資料後，會回答三個問題：

- 該轉職，還是留在原公司拚升遷？
- 未來 36 個月裡，哪幾個月是轉職或升遷的窗口？
- 什麼類型的公司（大型企業、新創、外商、公部門、自由接案、中小企業）最適合你？

## 功能

| 區塊 | 內容 |
|---|---|
| 綜合判讀 | 未來一年轉職／留任的結論、各 3 個最佳月份、八字四柱 |
| 每日職場運勢 | 今天與未來 7 天的職場指數，以及提案、談薪、面試、遞辭呈、請假的宜忌 |
| 時機曲線 | 36 個月的轉職動能與升遷動能折線圖；點選任一月份展開詳解（各系統訊號、建議行動、本月吉日） |
| 公司類型 | 六種環境的匹配分數與判斷依據，加上依喜用五行推薦的產業 |
| 八字 | 身強身弱、用神、十神能量分布、五行、大運、流年喜忌 |
| 紫微斗數 | 十二宮命盤、官祿宮主星解讀、流年四化對官祿與遷移宮的影響 |
| 奇門遁甲 | 今日巳時八門方位、未來 60 天適合面試／簽約／談薪的吉日 |
| 人類圖 | 類型、策略、內在權威、人生角色、九大中心圖、轉職的身體訊號 |
| 西洋星盤 | 天頂星座、第十宮行星、土星課題、目前木星行經的宮位 |
| 兩家 offer 比較 | 依公司類型、產業五行、職能、方位、報到日逐項打分，比出哪家較適合 |
| 現職適配度 | 檢查目前公司與命盤的契合度，指出卡住你的項目並給出建議 |
| 主管／同事合盤 | 八字五行生剋、日支合沖、人類圖電磁通道，給出相處與升遷策略 |
| 奇門指定日期擇時 | 選一天看 12 個時辰的值使門與開門方位，適合安排面試或談判 |
| IG 限動圖卡 | 產生 1080×1920 的結果圖卡，可下載或長按儲存 |
| 分享連結 | 把出生資料帶在網址參數裡，點開即直接看到結果 |

## 使用方式

純前端靜態網站，不需要建置或後端。

```
index.html          頁面結構
assets/style.css    樣式（含淺色／深色主題）
assets/engine.js    排盤與評分引擎
assets/tools.js     職涯工具箱、每日運勢、圖卡、分享連結
assets/app.js       主畫面渲染與事件綁定
```

- 直接用瀏覽器開啟 `index.html`，或
- 在 repo 設定中開啟 **GitHub Pages**（Settings → Pages → Branch: `main`、資料夾 `/ (root)`），即可取得公開網址。

所有計算都在瀏覽器內完成，出生資料不會上傳到任何伺服器。使用「分享連結」時，出生日期會出現在網址中，請只分享給信任的人。

## 計算方式

| 系統 | 使用的函式庫／方法 |
|---|---|
| 八字、黃曆、節氣 | [lunar-javascript](https://github.com/6tail/lunar-javascript) 1.7.3 |
| 紫微斗數 | [iztro](https://github.com/SylarLong/iztro) 2.5.8 |
| 星盤、人類圖行星位置 | [astronomy-engine](https://github.com/cosinekitty/astronomy) 2.1.19 |
| 奇門遁甲 | 自行實作：時家轉盤、拆補法定局，只排地盤三奇六儀與八門 |

時機曲線的分數是自訂加權模型：八字流年與流月、紫微流年四化、星盤木星／土星／天王星／冥王星行運，三者加權後換算成 0–100 的相對動能。

## 已知限制

- 八字以國曆時間排盤，未做真太陽時校正。
- 出生地時區不含夏令時間；1945–1979 年間在台灣出生且遇夏令時者，請將出生時間減 1 小時再輸入。
- 奇門遁甲為簡化版，不含九星、八神與天盤格局。
- 人類圖的月交點採平均交點，不是真實交點。
- 不確定出生時間時，紫微以午時排盤，星盤改用太陽宮位制，準確度會下降。
