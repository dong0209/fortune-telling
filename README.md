# 職運羅盤

**東西方十種命理，交叉比對你的職涯答案。** 只問一位命理師，你只會聽到一種說法。職運羅盤把八字、紫微斗數、易經、姓名學、梅花易數、九宮飛星、奇門遁甲等東方學派，和西洋星盤、生命靈數、人類圖等西方系統放在同一張表上，回答三個問題：

- 該轉職，還是留在原公司拚升遷？各學派的判斷一致還是分歧？
- 未來 36 個月裡，哪幾個月是轉職或升遷的窗口？
- 什麼類型的公司最適合你？

## 架構

```
docs/                       前端（GitHub Pages 從這個資料夾發布）
  index.html                主頁
  admin.html                管理後台：核對付款、開通會員
  privacy.html              隱私權與付費條款
  assets/config.js          網站設定：Supabase 金鑰、收款帳號
  assets/api.js             與 Supabase 溝通
  assets/render.js          依伺服器報告繪製畫面與鎖定卡
  assets/tools.js           工具箱、IG 圖卡、分享連結、登入與升級
  assets/sky.js             星空背景與星宿羅盤
supabase/                   後端
  migrations/               資料表、權限、核准開通函式
  functions/analyze/        排盤 API：查會員等級，只回傳該等級能看的內容
  functions/_shared/engine.js  排盤與評分引擎
```

- **排盤計算全部在伺服器端**。網頁拿不到超出會員等級的資料，也沒辦法在前端偷改等級。
- **出生資料只用於即時計算**，不會被儲存。

部署步驟請看 **[DEPLOY.md](DEPLOY.md)**。

## 計算方式

| 系統 | 使用的函式庫／方法 |
|---|---|
| 八字、黃曆、節氣 | [lunar-javascript](https://github.com/6tail/lunar-javascript) 1.7.3 |
| 紫微斗數 | [iztro](https://github.com/SylarLong/iztro) 2.5.8 |
| 星盤、人類圖行星位置 | [astronomy-engine](https://github.com/cosinekitty/astronomy) 2.1.19 |
| 奇門遁甲 | 自行實作：時家轉盤、拆補法定局，只排地盤三奇六儀與八門 |
| 真太陽時與夏令時間 | 以 IANA 時區資料庫（Intl）換算出生當地的歷史時區與夏令時間，再加經度修正與均時差 |
| 每日職場一卦 | 梅花易數字占：問題前後兩半的康熙筆畫起上下卦，加起卦時辰（台灣時間）得動爻 |

時機曲線的分數是自訂加權模型：
- 納入八字流年與流月、紫微流年四化，以及星盤的木星、土星、天王星、冥王星行運。
- 三者加權後，換算成 0–100 的相對動能。

## 已知限制

- 真太陽時的均時差採近似公式，誤差約 1 分鐘；出生時間剛好落在時辰交界時，建議兩種排法都看看（表單可關閉真太陽時）。
- 出生地只提供清單內的城市，經度以該城市為準。
- 奇門遁甲為簡化版，不含九星、八神與天盤格局。
- 人類圖的月交點採平均交點，不是真實交點。
