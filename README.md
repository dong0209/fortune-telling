# 職運羅盤

**觀東方之命，問西方之星，解你的職涯之惑。** 命盤、星圖、卦象、靈數，各自藏著一部分答案。職運羅盤將八字、紫微斗數、易經、姓名學、梅花易數、九宮飛星、奇門遁甲等東方術數，與西洋星盤、生命靈數、人類圖等西方系統合於一盤，讓它們彼此印證，回答三個問題：

- 該轉職，還是留在原公司拚升遷？各學派的判斷一致還是分歧？
- 未來 36 個月裡，哪幾個月是轉職或升遷的窗口？
- 什麼類型的公司最適合你？

## 架構

```
docs/                       前端（GitHub Pages 從這個資料夾發布）
  index.html                主頁
  admin.html                管理後台：核對付款、開通會員
  privacy.html              隱私權與付費條款
  assets/config.js          網站設定：Supabase 金鑰、收款帳號
  assets/api.js             與 Supabase 溝通
  assets/render.js          依伺服器報告繪製畫面與鎖定卡
  assets/nav.js             「我的命盤／今日」模式頁籤、籤筒目錄與區塊卦象
  assets/cities.js          出生地清單（網頁搜尋用，由 scripts/cities 產生）
  assets/sample.js          範例報告模式（?sample=free|paid|vip）
  assets/sample/            範例報告資料（由 tests/build-sample.mjs 產生）
  assets/tools.js           工具箱、IG 圖卡、分享連結、登入與升級
  assets/sky.js             星空背景與星宿羅盤
supabase/                   後端
  migrations/               資料表、權限、核准開通函式
  functions/analyze/        排盤 API：查會員等級，只回傳該等級能看的內容
  functions/_shared/engine.js  排盤與評分引擎
  functions/_shared/cities.js  出生地清單（伺服器排盤用，由 scripts/cities 產生）
scripts/cities/             從 GeoNames 產生出生地清單
tests/                      排盤引擎與出生地清單的測試
```

- **排盤計算全部在伺服器端**。網頁拿不到超出會員等級的資料，也沒辦法在前端偷改等級。
- **出生資料只用於即時計算**，不會被儲存。唯一的例外是會員登入後主動勾選「記住我的生辰」，這筆資料存在 `birth_profiles`，只有本人能讀寫、刪除，會員後台也看不到。

部署步驟請看 **[DEPLOY.md](DEPLOY.md)**。

## 計算方式

| 系統 | 使用的函式庫／方法 |
|---|---|
| 八字、黃曆、節氣 | [lunar-javascript](https://github.com/6tail/lunar-javascript) 1.7.3 |
| 紫微斗數 | [iztro](https://github.com/SylarLong/iztro) 2.5.8 |
| 星盤、人類圖行星位置 | [astronomy-engine](https://github.com/cosinekitty/astronomy) 2.1.19 |
| 奇門遁甲 | 自行實作：時家轉盤、拆補法定局，只排地盤三奇六儀與八門 |
| 真太陽時與夏令時間 | 以 IANA 時區資料庫（Intl）換算出生當地的歷史時區與夏令時間，再加經度修正與均時差 |
| 每日職場一卦 | 梅花易數字占：問題前後兩半的康熙筆畫起上下卦，加起卦時辰（台灣時間）得動爻 |

時機曲線的分數是自訂加權模型：
- 納入八字流年與流月、紫微流年四化，以及星盤的木星、土星、天王星、冥王星行運。
- 三者加權後，換算成 0–100 的相對動能。

## 測試

```bash
cd tests && npm install && npm test
```

- 八字四柱以獨立的曆法公式驗證（日柱以 1900-01-01 甲戌日推算、五虎遁、五鼠遁），不依賴排盤函式庫本身。
- 真太陽時、夏令時間、南北半球時區都挑時辰交界的案例。
- 出生地清單：舊版 28 筆編號不變（分享連結靠編號記錄出生地）、前後端一致、台灣 368 個鄉鎮市區。
- 會員等級與回歸快照（`tests/fixtures/reports.json`）。排盤或評分邏輯有預期內的變動時，執行 `npm run update-snapshots` 更新快照。

推送到 main 或開 PR 時，GitHub Actions 會自動執行測試。

## 範例報告

網址加上 `?sample=free`、`?sample=paid` 或 `?sample=vip`，會顯示虛構人物「張三豐」在各等級實際看到的報告，讓訪客在贊助前知道會拿到什麼。鎖定卡與贊助視窗都有「看範例報告」的連結。

- 資料事先算好放在 `docs/assets/sample/`，範例模式不會呼叫伺服器。交叉比對（預設學派組合）、月份詳解、奇門擇時都能操作；offer 比較、合盤等需要自行輸入的功能會提示先用自己的生日排盤。
- VIP 範例中，梅花易數、九宮飛星、奇門遁甲、人類圖只露出上半部，下方模糊處理。
- 排盤或評分邏輯改變後，執行 `cd tests && npm run build-sample` 重新產生；範例過期時測試會失敗提醒。

## 已知限制

- 真太陽時的均時差採近似公式，誤差約 1 分鐘；出生時間剛好落在時辰交界時，建議兩種排法都看看（表單可關閉真太陽時）。
- 出生地收錄台灣 368 個鄉鎮市區與約 2,400 個海外城市（資料來源 GeoNames，CC BY 4.0），經度以該地點為準；清單外的地點請選鄰近城市。
- 奇門遁甲為簡化版，不含九星、八神與天盤格局。
- 人類圖的月交點採平均交點，不是真實交點。
